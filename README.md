# Fantasy Premier League (FPL) 26/27 Dashboard

## What is it?
Just a little vibe-coding project for the current FPL season!

## How it works
1. Pulls in live FPL data from the API endpoint: https://fantasy.premierleague.com/api/bootstrap-static/
2. Compiles the relevant data into a Pandas Dataframe
3. Plots the selected variables on a chart of your choice

## What can you do?
* Select your chart
  * Scatter
  * Line
  * Bar
* Filter by top N players of your liking using a slider (or None at all)
